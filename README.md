# «Русское» — плагин для Lampa

Раздел с российскими фильмами и сериалами для [Lampa](https://github.com/yumata/lampa): цветные плитки-подборки по кинотеатрам, телеканалам, жанрам и годам.

Плагин работает **только как каталог**: данные берутся из TMDB, видео он не содержит и ничего не воспроизводит сам.

## Установка

1. В Lampa откройте **Настройки → Расширения → Добавить плагин**.
2. Введите адрес:
   ```
   https://89killreal.github.io/lampa/rus_menu.js
   ```
3. Перезапустите Lampa. В левом меню появятся пункты **«Русское»** и **«Детское»**.

## Что внутри

- **Личное:** «Продолжить смотреть» (недавно открытое), «Новые серии ваших сериалов» (из закладок и истории: вышедшие за 2 недели и ближайшие), «Скоро выйдет» с обратным отсчётом до премьеры.
- **Сейчас смотрят:** популярные фильмы и сериалы, новинки онлайн-кинотеатров, сериалы с новыми сериями на этой неделе, случайный фильм с рейтингом 7+.
- **Онлайн-кинотеатры:** Кинопоиск, Okko, Иви, Wink, START, PREMIER, KION, more.tv, Амедиатека. Сериалы есть у всех. Фильмы есть там, где TMDB знает, в каком кинотеатре их можно посмотреть.
- **Телеканалы:** Первый канал, НТВ, ТНТ, СТС.
- **Мультфильмы, фильмы и сериалы, подборки** (рейтинг 7+, короткие, мини-сериалы, завершённые), **по годам**, **жанры**.
- **«Детское»:** мультфильмы, мультсериалы, советская классика, семейные фильмы и сказки, без взрослых жанров.

На каждой плитке подписано, как отсортирована подборка: «популярные», «новинки», «лучшие по оценкам» или «известные». Подборки, в которых меньше 6 фильмов, не показываются.

## Настройки

**Настройки → Русское:**

| Пункт | По умолчанию |
|---|---|
| Размер плиток | Обычные |
| Обложки на плитках | Вкл |
| Пункт «Детское» в меню | Вкл |
| Показывать 18+ | **Выкл** |
| «Назад» без окна страниц | Выкл |
| Блоки и кинотеатры по отдельности | Вкл |
| Личные блоки (продолжить, новые серии, скоро выйдет) | Вкл |
| Сбросить настройки и кэш | — |

## Если ничего не грузится

TMDB в России часто открывается медленно или не открывается вовсе. Попробуйте:

- в Lampa включить **Настройки → TMDB → проксирование**;
- или пустить `themoviedb.org`, `tmdb.org`, `image.tmdb.org` и `api.themoviedb.org` через VPN на роутере.

Если TMDB недоступен, плагин сам покажет об этом сообщение и кнопку «Повторить».

## Обновления

После обновления плагина Lampa при запуске сообщит: «Плагин «Русское» обновлён до версии N». Текущая версия указана в **Настройки → Русское → Сбросить настройки и кэш**.
